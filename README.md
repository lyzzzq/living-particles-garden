# 生长 · GROWTH

使用 HTML、CSS、JavaScript、p5.js 与 ml5.js Hand Pose 的全屏植物绘画课程项目。

## 使用

在 VS Code 打开仓库，右键 index.html → Open with Live Server。点击「开启手势」并允许摄像头。依赖和模型需要联网加载。

拇指食指捏合一下种一朵花，松开后再捏可继续；移动生长草藤与碎花，张掌绽放，握拳闭合。鼠标模式点击种花，空格绽放，F 闭合。

点击「开启声音」试听轻风、微弱慢速旋律与交互铃音，可调音量或关闭。花色自动随机；早期图形随创作渐隐，为新植物留出位置。

详细操作见 [使用说明](使用说明.md)。

## 检查

安装 Node.js 后运行 npm test。测试使用模拟输入，真实摄像头舒适度、速度和实际听感仍需设备试听。

## 开场播种节奏

第一次成功播种为中等花；第二、第三次为不同花型的大花，从花苞自动展开到明显可见的程度，张掌可进一步完全绽放。第四朵回到较小的花，后续继续大小随机、配色随机。大花靠近画面边缘时优先调整到附近合适的位置，拥挤时让早期底景或小花渐隐，为主花保留空间；开场两朵大花不会因紧接着种下一朵而互相替换。

## 花色节奏与主花细节

前四次成功播种使用四个不同主色系；之后每连续三朵避开重复色系，较早出现的颜色仍可以再次使用。配色由程序自动安排，不增加选择框。

大花以一个主色为主，少量花瓣采用两种协调辅色，保留灰绿、淡紫等局部色斑。缓存花瓣纹理增加根部较深、外缘较亮的渐变色阶，增加卷瓣层次与细花蕊；主要粒子纹理继续缓存复用。
