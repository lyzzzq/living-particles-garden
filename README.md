# 生长 · GROWTH

使用 HTML、CSS、JavaScript、p5.js 与 ml5.js Hand Pose 的全屏植物绘画课程项目。

## 正式作品链接

[打开「生长 · GROWTH」](https://growth-garden-lyzzzq.pages.dev/)

## 使用

在 VS Code 打开仓库，右键 index.html → Open with Live Server。点击「开启手势」并允许摄像头。依赖和模型需要联网加载。

张开手掌种一朵花并让附近花朵绽放；收拢手指后再张掌可继续种花。伸出食指移动生长草藤与碎花，握拳让附近花朵闭合。握拳允许一根手指识别不准，但伸直食指移动不会触发闭合。鼠标模式点击种花，空格绽放，F 闭合。

点击「开启声音」试听轻风、微弱慢速旋律与交互铃音，可调音量或关闭。花色自动随机；早期图形随创作渐隐，为新植物留出位置。

详细操作见 [使用说明](使用说明.md)。

## 开场播种节奏

前七次成功播种按「中、大、小、大、中、大、小」交错，大花在第 2、4、6 次出现。之后继续大小随机。大花优先寻找合适空位，保留自动绽放、手势开合、缓慢摆动和边缘粒子。

## 花色节奏与主花细节

前七次成功播种使用七个不同主色系，大花避开已种过的花型；之后每连续三朵避开重复色系，较早出现的颜色仍可以再次使用。配色由程序自动安排，不增加选择框。

大花以一个主色为主，少量花瓣采用两种协调辅色，保留灰绿、淡紫等局部色斑。缓存花瓣纹理增加根部较深、外缘较亮的渐变色阶，增加卷瓣层次与细花蕊；主要粒子纹理继续缓存复用。


## 手机使用

支持手机竖屏、横屏和刘海屏安全区域；底部控件与花朵构图随可用画面调整。

- 触屏绘画：轻点种花，滑动生长藤蔓；拖动不会误种花。用底部「绽放」「闭合」按钮控制附近花朵，不需要键盘。
- 手势绘画：点击「开启手势」，优先请求前置摄像头。预览和识别标记按同一比例显示；切回触屏绘画会关闭摄像头。
- 旋转屏幕时保留已画内容，并调整花朵和藤蔓的位置与比例。
- 已检查 320×568、375×667、390×844、430×932、844×390 等尺寸；触屏事件与摄像头生命周期有模拟检查，真实手机摄像头和实际听感仍需设备验证。
