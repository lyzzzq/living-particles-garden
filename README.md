# 浮游花园 · Living Particles

全屏手势花园课程期末项目，使用 HTML、CSS、JavaScript、p5.js 与 ml5.js Hand Pose。

## 启动

在 VS Code 打开本仓库，右键 index.html，选择 Open with Live Server。在 localhost 页面点击「开启手势」，允许摄像头访问。依赖与识别模型需要联网加载。

## 操作

- 指尖在同一位置停留一秒：种下一朵随机大小、花型的花。移动到新位置可再次种植。
- 移动：短暂粒子反馈，以及有疏密变化的短草、藤蔓和多色碎花群。
- 张掌：附近花朵绽放；握拳：附近花朵闭合。
- 鼠标也可练习；空格模拟张掌，F 模拟握拳。
- 「收藏画作」保存 PNG，排除蝴蝶光标与界面。

## 文件与检查

index.html 是页面，style.css 是全屏样式，sketch.js 是绘制与手势逻辑。详细说明见 [使用说明](使用说明.md)。已提供两张离屏预览，它们不是浏览器实拍截图。

安装 Node.js 后运行 npm test，检查停留触发、随机大小、草花藤变化、连接、反馈消退和模型就绪流程。测试使用模拟输入；真实摄像头速度和浏览器视觉仍需实测。
